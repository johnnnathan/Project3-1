🌀 Event Shuffle ℹ × Event Shuffle randomly reorders events within each time interval (chunk) to preserve privacy while keeping general temporal structure.
Interval: Time window (ms) to define the size of each chunk.

🧩 Frame Shuffle ℹ × Frame Shuffle randomizes the order of entire frames (chunks of events). Preserves local event structure within frames but breaks the global temporal sequence.

🌫️ Frame Blur ℹ × Frame Blur applies spatial Gaussian smoothing to each frame of events. Reduces spatial detail while preserving general activity patterns.
σ (sigma): Controls the strength of the blur. Larger σ = stronger blur.
